# App screens

Real renders of `apps/borewell-native`, captured at 390x844 (iPhone-class)
from `npm run web` running against the in-memory demo backend
(`services/demo.js`) - not mockups. Map tiles were blocked during capture,
which is why the maps are flat grey; on a real run they show
OpenStreetMap.
